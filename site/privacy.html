개인정보처리방침

Auto Input은 사용자가 웹 입력 업무를 직접 자동화할 수 있도록 돕는 PC 앱 및 Chrome 확장프로그램 서비스입니다. Auto Input은 서비스 제공에 필요한 최소한의 개인정보만 처리하며, 사용자가 구성한 자동화 데이터와 웹페이지 내용을 불필요하게 수집하거나 판매하지 않습니다.

시행일: 2026년 6월 8일

1. 처리하는 개인정보 항목

Auto Input은 아래 정보를 처리할 수 있습니다.

  • 회원 식별 정보: Google 로그인으로 제공되는 이메일 주소, 표시 이름, 프로필 이미지, Firebase UID
  • 서비스 이용 정보: 가입 일시, 로그인 상태, 플랜 정보, 무료체험 시작일, 라이선스 상태
  • 결제 관련 정보: 결제 승인 결과, 주문 번호, 결제 상품명, 결제 상태, 결제 일시
  • 고객 문의 정보: 사용자가 이메일로 문의할 때 제공하는 이메일 주소와 문의 내용
  • 자동화 설정 정보: 프로젝트명, 대상 URL, 매핑 selector, 플로우 단계, 단축키 설정, 데이터 컬럼명

사용자가 직접 업로드한 CSV, XLS, XLSX 파일의 실제 행 데이터는 PC 앱 내에서 자동화 실행을 위해 사용됩니다. 현재 서비스는 해당 파일의 원본 내용을 서버에 저장하는 기능을 목적으로 하지 않습니다.

2. 개인정보 처리 목적

Auto Input은 수집한 정보를 다음 목적에 사용합니다.

  • Google 로그인 기반 회원 식별 및 계정 관리
  • 무료 플랜, 무료체험, Pro 플랜 등 라이선스 상태 확인
  • 프로젝트 개수 제한 및 유료 기능 사용 가능 여부 확인
  • NicePay 결제 처리 결과 확인 및 결제 후 플랜 반영
  • 사용자 문의 응대, 오류 확인, 서비스 공지 전달
  • 보안 사고, 부정 사용, 정책 위반 행위 확인 및 대응

3. Chrome 확장프로그램 권한 사용

Auto Input Chrome 확장프로그램은 PC 앱과 실제 웹페이지 사이에서 사용자가 선택한 입력창, 버튼 등 웹 요소를 매핑하고 자동화 명령을 실행하기 위해 사용됩니다.

  • activeTab: 사용자가 매핑 또는 실행 기능을 활성화한 현재 탭에만 접근하기 위해 사용합니다.
  • scripting: 사용자가 기능을 실행한 탭에 content script를 삽입하여 매핑과 자동화 실행을 처리하기 위해 사용합니다.
  • storage: 확장프로그램의 간단한 설정과 상태를 저장하기 위해 사용합니다.
  • 선택적 사이트 권한: 사용자가 특정 사이트에서 매핑 또는 실행을 시작할 때만 요청합니다.

확장프로그램은 사용자가 기능을 활성화하지 않은 상태에서 방문하는 모든 웹페이지의 내용을 상시 수집하지 않습니다.

4. 자동화 데이터 처리 방식

Auto Input은 사용자가 직접 설정한 대상 URL, 웹 요소 selector, 입력 값, 클릭 단계 등을 기반으로 자동화를 실행합니다. 이러한 정보는 사용자의 프로젝트를 재사용할 수 있도록 앱 또는 서비스 저장소에 보관될 수 있습니다.

사용자가 자동화 대상으로 선택한 외부 웹사이트의 개인정보 처리와 이용약관은 해당 웹사이트의 정책을 따릅니다. 사용자는 자동화 실행 전 대상 웹사이트의 약관과 관련 법령을 준수해야 합니다.

5. 개인정보 보관 기간

Auto Input은 개인정보를 처리 목적 달성에 필요한 기간 동안 보관합니다.

  • 회원 및 라이선스 정보: 회원 탈퇴 또는 서비스 이용 종료 요청 시까지
  • 결제 기록: 전자상거래 및 세무 관련 법령에서 요구하는 기간 동안
  • 문의 기록: 문의 처리 완료 후 분쟁 대응을 위해 필요한 기간 동안
  • 자동화 설정 정보: 사용자가 삭제하거나 계정 삭제를 요청할 때까지

법령상 보관 의무가 없는 정보는 목적 달성 후 지체 없이 삭제하거나 식별할 수 없도록 처리합니다.

6. 개인정보 제3자 제공

Auto Input은 사용자의 개인정보를 판매하지 않습니다. 다만 다음 경우에는 필요한 범위에서 정보가 제공되거나 처리될 수 있습니다.

  • 사용자가 사전에 동의한 경우
  • 법령에 따라 수사기관 또는 공공기관의 적법한 요청이 있는 경우
  • 결제 처리를 위해 NicePay 등 결제대행사에 결제에 필요한 정보가 전달되는 경우

7. 개인정보 처리 위탁 및 이용 서비스

Auto Input은 서비스 운영을 위해 다음 외부 서비스를 사용할 수 있습니다.

  • Firebase Authentication: Google 로그인 및 사용자 인증
  • Firebase Firestore: 라이선스, 플랜, 서비스 설정 정보 저장
  • Firebase Hosting: 웹사이트 및 안내 페이지 호스팅
  • NicePay: 유료 플랜 결제 승인 및 결제 결과 처리
  • Google Chrome Web Store: 확장프로그램 배포

8. 개인정보의 안전성 확보 조치

Auto Input은 개인정보 보호를 위해 다음 조치를 적용합니다.

  • Firebase 인증을 통한 사용자 식별
  • 결제 Secret Key 등 민감한 서버 키의 클라이언트 노출 방지
  • 서비스 접근 권한을 필요한 범위로 제한
  • 불필요한 개인정보 수집 최소화
  • 문제 발생 시 로그 확인 및 접근 권한 점검

9. 이용자의 권리

사용자는 본인의 개인정보에 대해 다음 권리를 요청할 수 있습니다.

  • 개인정보 열람 요청
  • 잘못된 개인정보 정정 요청
  • 계정 및 개인정보 삭제 요청
  • 개인정보 처리 정지 요청

요청은 아래 문의 이메일로 접수할 수 있으며, 본인 확인 후 관련 법령에 따라 처리합니다.

10. 아동의 개인정보

Auto Input은 만 14세 미만 아동을 주요 대상으로 제공되는 서비스가 아닙니다. 만 14세 미만 아동의 개인정보가 처리된 사실을 확인하면 지체 없이 삭제하거나 필요한 조치를 취합니다.

11. 개인정보처리방침 변경

본 방침은 서비스 기능, 법령, 외부 서비스 변경에 따라 수정될 수 있습니다. 중요한 변경이 있는 경우 웹사이트 또는 앱 내 공지를 통해 안내합니다.
