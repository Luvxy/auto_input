Q/A

자주 묻는 질문

Auto Input을 설치하고 처음 자동화를 실행할 때 자주 생기는 질문을 모았습니다. 문제가 계속되면 화면 캡처와 함께 문의해 주세요.

시작하기

Auto Input은 어떤 프로그램인가요?

Auto Input은 사용자가 직접 웹사이트의 입력창과 버튼을 매핑하고, 엑셀이나 CSV 데이터와 연결해 반복 입력 업무를 자동화하는 PC 앱입니다. PC 앱에서 자동화 흐름을 만들고, Chrome 확장프로그램이 실제 웹페이지에서 입력과 클릭을 실행합니다.

설치하려면 무엇이 필요한가요?

Windows PC, Chrome 브라우저, Auto Input PC 앱, Auto Input Chrome 확장프로그램이 필요합니다. 먼저 PC 앱을 설치한 뒤 Chrome Web Store에서 확장프로그램을 설치하고 Google 계정으로 로그인하면 됩니다.

처음에는 무엇부터 해보면 좋나요?

사이트의 테스트 페이지에서 예시 고객 등록 자동화를 먼저 실행해보는 것을 권장합니다. PC 앱에서 예시 프로젝트를 만들면 대상 URL과 기본 매핑이 자동으로 준비됩니다.

로그인과 요금제

왜 Google 로그인이 필요한가요?

Google 로그인은 사용자의 무료 프로젝트 개수, 무료체험 여부, Pro 결제 상태를 확인하기 위해 사용됩니다. 이메일, 표시 이름, Firebase UID 등 계정 식별에 필요한 최소 정보만 사용합니다.

무료로 사용할 수 있나요?

네. 무료 플랜에서는 프로젝트 2개까지 사용할 수 있습니다. 더 많은 프로젝트가 필요하면 Pro 플랜을 사용할 수 있고, 무료체험이 제공되는 경우 앱 안에서 7일간 제한 없이 테스트할 수 있습니다.

결제 후 바로 Pro가 적용되지 않으면 어떻게 하나요?

결제 완료 페이지 안내에 따라 앱으로 돌아간 뒤 라이선스 새로고침을 눌러주세요. 그래도 반영되지 않으면 결제 시간, 로그인 이메일, 결제 화면 캡처를 함께 보내주시면 확인해드리겠습니다.

Chrome 확장프로그램

확장프로그램이 사이트 권한을 요청하는 이유는 무엇인가요?

Auto Input은 사용자가 선택한 웹페이지에서 입력창과 버튼을 찾고 자동화 명령을 실행해야 합니다. 그래서 매핑 또는 실행 기능을 켰을 때 현재 사이트에 대한 권한을 요청합니다. 일반 사이트 방문만으로 모든 페이지 내용을 상시 수집하지 않습니다.

매핑이 안 될 때는 어떻게 확인하나요?

PC 앱이 켜져 있는지, 확장프로그램이 설치되어 있는지, 현재 사이트 권한을 허용했는지 확인해 주세요. 그다음 PC 앱에서 매핑 모드를 켜고 웹페이지의 입력창이나 버튼을 다시 클릭해보면 됩니다.

대상 페이지는 앱 안에서 열리나요?

대상 페이지는 기본 브라우저에서 열립니다. 실제 웹사이트 자동화는 Chrome 확장프로그램을 통해 실행되기 때문에, 앱 내부 브라우저가 아니라 사용자의 Chrome 탭에서 동작합니다.

데이터와 자동화 실행

엑셀 파일도 사용할 수 있나요?

네. CSV, XLSX, XLS 파일을 불러올 수 있습니다. 첫 번째 행은 컬럼명으로 사용되며, 플로우 단계에서 컬럼명을 선택해 입력값으로 연결할 수 있습니다.

자동화 실행 중 멈출 수 있나요?

네. 전체 실행 중에는 앱 상단과 실행 화면에 중지 버튼이 표시됩니다. 중지를 누르면 반복 실행을 멈추고, 실제 웹페이지 실행 중인 경우 확장프로그램으로 중지 요청을 보냅니다.

단축키 실행은 어떤 용도인가요?

단축키 실행은 사용자가 직접 특정 순간에 자동화 플로우를 실행하고 싶을 때 사용합니다. 프로젝트당 최대 3개의 단축키 플로우를 만들 수 있고, 실행 후 다음 데이터로 넘어갈지 선택할 수 있습니다.

문제 해결

로그인이 되지 않으면 어떻게 하나요?

Chrome에서 Google 로그인을 완료한 뒤 앱으로 돌아가 주세요. 계속 실패하면 앱을 완전히 종료한 후 다시 실행하고, 같은 Google 계정으로 다시 로그인해보세요.

자동화가 엉뚱한 곳에 입력되면 어떻게 하나요?

대상 사이트 구조가 바뀌었거나 매핑한 요소가 잘못되었을 수 있습니다. 기존 매핑을 삭제한 뒤 현재 페이지에서 입력창과 버튼을 다시 매핑하고 1건 테스트 실행으로 먼저 확인해 주세요.
