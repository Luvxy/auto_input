Chrome 확장프로그램 설치

Auto Input 확장프로그램이 Chrome Web Store에 등록되었습니다. 이제 개발자 모드 설치 없이 스토어에서 바로 설치할 수 있습니다.

Chrome Web Store에서 설치 PC 앱 다운로드

설치 순서

  1. 위의 Chrome Web Store에서 설치 버튼을 누릅니다.
  2. Chrome Web Store 페이지에서 Chrome에 추가를 누릅니다.
  3. 권한 안내를 확인하고 확장프로그램 추가를 승인합니다.
  4. Auto Input PC 앱을 실행하고 Google 계정으로 로그인합니다.
  5. 자동화할 웹페이지를 Chrome에서 엽니다.
  6. 확장프로그램 아이콘을 누르고 매핑 모드 켜기를 선택합니다.
  7. 웹페이지의 입력창과 버튼을 클릭해 PC 앱에 매핑합니다.

권한 안내

Auto Input은 사용자가 매핑 모드나 실행 기능을 켰을 때 현재 탭에서 입력창과 버튼을 찾기 위해 권한을 요청합니다. 일반 사이트 방문만으로 모든 페이지 내용을 상시 수집하지 않습니다.

연결 확인

PC 앱 상단에 Bridge ON이 표시되면 확장프로그램과 앱이 연결된 상태입니다. 매핑이 들어오지 않으면 PC 앱이 실행 중인지, 현재 사이트 권한을 허용했는지, 대상 페이지를 새로고침했는지 확인해 주세요.
